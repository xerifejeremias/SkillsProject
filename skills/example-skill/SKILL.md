# Example skill

Replace this with your skill's instructions. Claude follows the body of this file once it decides to use the skill.

## Steps

1. Read the file the user named.
2. Write a summary of exactly three bullet points that covers the main ideas.
3. If the file is longer than a few pages, end with a single line naming the section that matters most.

Longer reference material can go in separate files next to this one (for example `reference.md`), linked from here so that Claude reads them only when needed.
